📊 SO SÁNH TCP VÀ UDP
════════════════════════════════════════════════════════════════════════════════

TCP (Transmission Control Protocol)
├─ Kết nối: ✅ Phải kết nối trước
├─ Tin cậy: ✅ Đảm bảo gửi đến, thứ tự
├─ Tốc độ: ❌ Chậm (kiểm soát lỗi)
├─ Biên tin: ❌ Phải tự định nghĩa (dòng)
├─ Ví dụ: TCP ví dụ 4.2, 4.3
└─ Dùng khi: Chat, file transfer, API

UDP (User Datagram Protocol)
├─ Kết nối: ❌ Gửi trực tiếp
├─ Tin cậy: ❌ Không bảo đảm
├─ Tốc độ: ✅ Nhanh
├─ Biên tin: ✅ Mỗi gói hoàn chỉnh
├─ Ví dụ: UDP ví dụ 4.4
└─ Dùng khi: Streaming, gaming, DNS

🔑 KỸ THUẬT CHÍNH
════════════════════════════════════════════════════════════════════════════════

✅ UTF-8 (Bảo toàn tiếng Việt):
   new InputStreamReader(stream, StandardCharsets.UTF_8)
   new OutputStreamWriter(stream, StandardCharsets.UTF_8)

✅ Try-with-resources (Tự động đóng):
   try (Resource resource = new Resource()) {
       // code
   }  // resource tự động đóng

✅ Thread Pool (Quản lý client):
   ExecutorService pool = Executors.newFixedThreadPool(20);
   pool.submit(() -> serve(socket));

✅ Giao thức dòng (TCP):
   out.println("PING");              // Gửi + \n
   String response = in.readLine();  // Đọc cho tới \n

✅ Timeout UDP (Không chờ vô hạn):
   socket.setSoTimeout(3000);  // 3 giây
   try {
       socket.receive(packet);
   } catch (SocketTimeoutException e) {
       // Hết thời gian
   }

✅ Datagram UDP (Mỗi gói đầy đủ):
   byte[] data = message.getBytes(UTF_8);
   int length = packet.getLength();  // ← QUAN TRỌNG
   String msg = new String(packet.getData(), 0, length, UTF_8);

⚠️ NHỮNG LỖI THƯỜNG GẶP
════════════════════════════════════════════════════════════════════════════════

❌ "Address already in use"
   → Đợi 1-2 phút hoặc đổi port

❌ "Connection refused"
   → Server không chạy hoặc port sai

❌ "Socket timeout" (UDP)
   → Server không phản hồi, kiểm tra firewall

❌ Tiếng Việt bị lỗi (ký tự???)
   → Sử dụng StandardCharsets.UTF_8

❌ Client chờ vô hạn (UDP)
   → Thiết lập socket.setSoTimeout(ms)

❌ "Port denied" (port < 1024)
   → Dùng port >= 1024 hoặc chạy với admin
