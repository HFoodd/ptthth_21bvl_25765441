CÂU HÌNH BAN ĐẦU:
─────────────────────────────────────────────────────────────────────────────
1. Yêu cầu: Java 17 trở lên
   Kiểm tra: java --version

2. Biên dịch tất cả file:
   javac -d bin src/network/*.java src/tcp/*.java src/udp/*.java src/exercise/*.java


VÍ DỤ 4.1 - KHẢO SÁT ĐỊA CHỈ MẠNG (HostInspector)
─────────────────────────────────────────────────────────────────────────────
Mô tả:  Sử dụng InetAddress để phân giải hostname, xác định loại IP, 
        loopback, site local

Biên dịch:
  javac -d bin src/network/HostInspector.java

Chạy:
  java -cp bin network.HostInspector localhost
  java -cp bin network.HostInspector example.com
  java -cp bin network.HostInspector 8.8.8.8
  java -cp bin network.HostInspector host-khong-ton-tai.invalid

Kết quả mong đợi:
  - localhost: Loopback = true
  - example.com: IP hợp lệ, Loopback = false
  - host-khong-ton-tai.invalid: Lỗi "Không phân giải được"


VÍ DỤ 4.2 - TCP SERVER TUẦN TỰ (TcpCommandServer)
─────────────────────────────────────────────────────────────────────────────
Mô tả:  Server lắng nghe kết nối, nhận lệnh từ client, phục vụ tuần tự
        (một client tại một thời điểm)

PORT: 5000

Biên dịch:
  javac -d bin src/tcp/TcpCommandServer.java src/tcp/TcpCommandClient.java

TERMINAL 1 - Chạy Server:
  java -cp bin tcp.TcpCommandServer

TERMINAL 2 - Chạy Client:
  java -cp bin tcp.TcpCommandClient localhost 5000

Các lệnh để test:
  PING                    → OK PONG
  TIME                    → OK [thời gian hiện tại]
  UPPER xin chào Việt Nam → OK XIN CHÀO VIỆT NAM
  UPPER hello             → OK HELLO
  ABC                     → ERR UNKNOWN_COMMAND
  QUIT                    → OK BYE (thoát)

Hạn chế:
  - Server chỉ phục vụ một client tại một thời điểm
  - Nếu có client khác kết nối phải chờ


VÍ DỤ 4.3 - TCP SERVER ĐA CLIENT (MultiClientTcpServer)
─────────────────────────────────────────────────────────────────────────────
Mô tả:  Server sử dụng Thread Pool để phục vụ nhiều client cùng lúc

PORT: 5000 (tương tự Ví dụ 4.2)

Biên dịch:
  javac -d bin src/tcp/MultiClientTcpServer.java src/tcp/TcpCommandServer.java

TERMINAL 1 - Chạy Server:
  java -cp bin tcp.MultiClientTcpServer

TERMINAL 2, 3, 4 - Chạy 3 Clients cùng lúc:
  java -cp bin tcp.TcpCommandClient localhost 5000
  java -cp bin tcp.TcpCommandClient localhost 5000
  java -cp bin tcp.TcpCommandClient localhost 5000

Kiểm thử:
  - Gửi lệnh từ các client cùng lúc
  - Quan sát server nhận các lệnh đồng thời
  - Đóng một client (gửi QUIT)
  - Hai client còn lại tiếp tục hoạt động bình thường

Lợi ích:
  - Nhiều client có thể kết nối cùng lúc
  - Không bị chặn tuần tự
  - Số luồng bị giới hạn (tối đa 20 clients)


VÍ DỤ 4.4 - UDP ECHO SERVER (UdpEchoServer)
─────────────────────────────────────────────────────────────────────────────
Mô tả:  Server UDP nhận datagram, gửi lại với tiền tố "ACK"

PORT: 5001

Biên dịch:
  javac -d bin src/udp/UdpEchoServer.java src/udp/UdpEchoClient.java

TERMINAL 1 - Chạy Server:
  java -cp bin udp.UdpEchoServer

TERMINAL 2 - Chạy Client (mỗi lần một lệnh):
  java -cp bin udp.UdpEchoClient localhost 5001 "xin chào UDP"
  java -cp bin udp.UdpEchoClient localhost 5001 "hello"
  java -cp bin udp.UdpEchoClient 192.168.1.10 5001 "test"

Kết quả mong đợi:
  Nhập: "xin chào UDP"    → Nhận: "ACK XIN CHÀO UDP"
  Nhập: "hello"           → Nhận: "ACK HELLO"

Test timeout:
  java -cp bin udp.UdpEchoClient localhost 9999 "test"
  (Server không chạy trên port 9999)
  → Kết quả: "Hết 3 giây nhưng chưa nhận được phản hồi"

Khác biệt với TCP:
  - Không cần kết nối trước
  - Nhanh hơn nhưng không đảm bảo gửi tới
  - Mỗi gói là độc lập


BÀI TẬP 1 - CHUYỂN CHỮ SỐ THÀNH CHỮ (Ex1_DigitToText)
─────────────────────────────────────────────────────────────────────────────
Mô tả:  Client gửi một chữ số (0-9), server trả về cách đọc tiếng Việt

PORT: 5010

Biên dịch:
  javac -d bin src/exercise/Ex1_DigitToText.java

TERMINAL 1 - Chạy Server:
  java -cp bin exercise.Ex1_DigitToText server

TERMINAL 2 - Chạy Client:
  java -cp bin exercise.Ex1_DigitToText client localhost 5010

Các lệnh để test:
  0          → OK Không
  1          → OK Một
  5          → OK Năm
  9          → OK Chín
  10         → ERR INVALID_DIGIT
  a          → ERR INVALID_DIGIT
  (rỗng)     → ERR INVALID_DIGIT
   5  (có space) → OK Năm
  QUIT       → OK BYE

Yêu cầu kiểm thử:
  ✓ Nhập chữ số hợp lệ (0-9)
  ✓ Nhập số > 9
  ✓ Nhập chuỗi rỗng
  ✓ Nhập ký tự chữ
  ✓ Nhập có khoảng trắng


BÀI TẬP 2 - DỊCH VỤ NGÀY GIỜ TCP/UDP (Ex2_DateTimeService)
─────────────────────────────────────────────────────────────────────────────
Mô tả:  Server TCP/UDP trả về ngày giờ theo yêu cầu
        Format: dd/MM/yyyy và HH:mm:ss

TCP PORT: 5011
UDP PORT: 5012

Biên dịch:
  javac -d bin src/exercise/Ex2_DateTimeService.java

TCP - TERMINAL 1 - Chạy Server:
  java -cp bin exercise.Ex2_DateTimeService tcp-server

TCP - TERMINAL 2 - Chạy Client (interactive):
  java -cp bin exercise.Ex2_DateTimeService tcp-client localhost 5011

Các lệnh TCP để test:
  DATE      → OK 27/09/2026
  TIME      → OK 14:30:45
  DATETIME  → OK 27/09/2026 14:30:45
  QUIT      → OK BYE

UDP - TERMINAL 3 - Chạy Server (trong terminal khác):
  java -cp bin exercise.Ex2_DateTimeService udp-server

UDP - TERMINAL 4 - Chạy Client (nhanh):
  java -cp bin exercise.Ex2_DateTimeService udp-client localhost 5012 DATE
  java -cp bin exercise.Ex2_DateTimeService udp-client localhost 5012 TIME
  java -cp bin exercise.Ex2_DateTimeService udp-client localhost 5012 DATETIME

Lưu ý:
  - TCP có QUIT để kết thúc phiên
  - UDP không cần QUIT (mỗi lệnh là độc lập)
  - Format ngày/giờ giống nhau trên cả TCP và UDP


BÀI TẬP 3 - MÁY TÍNH TỪ XA (Ex3_RemoteCalculator)
─────────────────────────────────────────────────────────────────────────────
Mô tả:  Client gửi "CALC toán_tử số1 số2", server trả kết quả

PORT: 5013

Biên dịch:
  javac -d bin src/exercise/Ex3_RemoteCalculator.java

TERMINAL 1 - Chạy Server:
  java -cp bin exercise.Ex3_RemoteCalculator server

TERMINAL 2 - Chạy Client:
  java -cp bin exercise.Ex3_RemoteCalculator client localhost 5013

Các lệnh để test:
  CALC + 100 200      → OK 300
  CALC - 50 10        → OK 40
  CALC * 5 6          → OK 30
  CALC / 10 2         → OK 5
  CALC / 20 4         → OK 5
  CALC / 10 0         → ERR DIVIDE_BY_ZERO
  CALC % 10 3         → ERR UNSUPPORTED_OPERATOR
  CALC + a 2          → ERR INVALID_NUMBER
  CALC + 5            → ERR INVALID_FORMAT
  CALC                → ERR INVALID_FORMAT
  QUIT                → OK BYE

Các phép toán hỗ trợ:
  + Cộng
  - Trừ
  * Nhân
  / Chia

Xử lý lỗi:
  - DIVIDE_BY_ZERO: Chia cho 0
  - INVALID_NUMBER: Toán hạng không phải số
  - INVALID_FORMAT: Định dạng lệnh sai
  - UNSUPPORTED_OPERATOR: Phép toán không hỗ trợ

HƯỚNG DẪN TEST TRÊN 2 MÁY (2 MACHINES)
════════════════════════════════════════════════════════════════════════════

Yêu cầu:
  1. Cả 2 máy cùng mạng LAN
  2. Biết IPv4 của máy server (sử dụng ipconfig hoặc ip addr)
  3. Firewall cho phép port

Ví dụ: Server có IP 192.168.1.100

Trên máy Server:
  java -cp bin tcp.TcpCommandServer     (hoặc multi-client)
  java -cp bin udp.UdpEchoServer

Trên máy Client:
  java -cp bin tcp.TcpCommandClient 192.168.1.100 5000
  java -cp bin udp.UdpEchoClient 192.168.1.100 5001 "test từ máy khác"

Firewall Windows:
  netsh advfirewall firewall add rule name="Java Socket Lab" \
    dir=in action=allow program="java.exe" protocol=tcp localport=5000

Firewall Linux:
  sudo ufw allow 5000/tcp
  sudo ufw allow 5001/udp

NHỮNG LỖI THƯỜNG GẶP VÀ CÁCH GIẢI QUYẾT
════════════════════════════════════════════════════════════════════════════

1. "Address already in use"
   → Cảng 5000/5001 đang bị dùng
   → Giải pháp: Đợi 1-2 phút, hoặc thay port trong code

2. "Connection refused"
   → Server không chạy hoặc port sai
   → Giải pháp: Chạy server trước, kiểm tra port

3. "Socket timeout"
   → UDP timeout, server không phản hồi
   → Giải pháp: Kiểm tra server đang chạy, firewall cho phép

4. Tiếng Việt bị lỗi (ký tự غريب)
   → Charset sai
   → Giải pháp: Luôn dùng StandardCharsets.UTF_8

5. Client chờ vô hạn
   → Không có timeout cho UDP
   → Giải pháp: Gọi socket.setSoTimeout(3000)
